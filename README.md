# ReadAble

Universal accessible document converter — turn PDFs, DOCX, and images into a personalized reading experience.

## Structure

```
frontend/   Next.js app (upload → process → profile → reader)
backend/    Processing API (reserved)
docs/       PRD, ERD, DESIGN
```

## Run frontend

```bash
cd frontend
pnpm install   # or npm install
pnpm dev
```
